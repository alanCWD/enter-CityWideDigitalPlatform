# Inbox sales landing page

Create a public, CityWide-branded sales page for Inbox that presents the existing dashboard product and the vision for an independent app that can also work within the CityWide suite.

- [ ] Introduce Inbox with a clear value proposition, a representative conversation interface, and benefits of bringing customer messages together. Match the existing marketing site's visual identity and make the page usable on mobile and desktop.
- [ ] Explain the existing dashboard Inbox separately from planned standalone availability and planned LINE integration. Present broadcasts, sequences and automations with appropriate availability qualifications; do not suggest every listed channel or feature is already fully operational without verification.
- [ ] Describe the potential benefits of connecting a LINE Official Account: customer conversations, rich message content and opportunities for broadcasts and automated follow-up. Clearly label these as planned, not currently connected. Explain that LINE requires an Official Account with Messaging API enabled, and that account messaging quotas and charges depend on LINE's regional plan.
- [ ] Use the reference as inspiration for the feature discussion, not as an integration provider. Do not use Zernio or claim LINE VOOM publishing is supported.
- [ ] Provide working paths to the existing dashboard Inbox and an existing sales contact or demo option, and make the page discoverable from the public site. Avoid invented standalone pricing or launch dates.
- [ ] Add appropriate page metadata and search discovery information. Preserve the current dashboard Inbox and other existing functionality.

This scope is the sales page and exploration of LINE's benefits. Building the standalone application or connecting LINE is future work and is not included in this change.
